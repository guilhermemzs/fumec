# Engenharia Diagnóstica e Acessibilidade | FUMEC

Site desenvolvido para o projeto de extensão da Universidade FUMEC, com foco na importância da Engenharia Diagnóstica na identificação de danos estruturais em elementos de acessibilidade.

O objetivo do site é apresentar, de forma visual e educativa, como a análise técnica de edificações pode contribuir para ambientes mais seguros, acessíveis e inclusivos.

## Sobre o projeto

O projeto aborda a relação entre engenharia civil, acessibilidade e segurança. A proposta é conscientizar alunos e a comunidade escolar sobre a importância de observar e diagnosticar problemas em elementos como:

- Rampas;
- Pisos táteis;
- Corrimãos;
- Escadas;
- Sinalizações;
- Áreas de circulação.

A Engenharia Diagnóstica permite identificar patologias construtivas, compreender suas causas e propor soluções que melhorem a segurança e a autonomia dos usuários.

## Tema

**Importância da Engenharia Diagnóstica na Avaliação de Danos Estruturais em Pontos de Acessibilidade.**

## Estrutura do site

O site possui as seguintes seções:

### Início

Apresentação principal do projeto, com destaque para o tema da acessibilidade segura.

### Projeto

Explicação sobre o objetivo geral, público-alvo e identificação do projeto.

### Atuação

Mostra como a Engenharia Diagnóstica atua, desde a observação inicial até a orientação técnica.

### Danos

Apresenta exemplos de problemas que podem comprometer a mobilidade, como trincas, desníveis, piso tátil danificado e corrimãos soltos.

### Metodologia

Explica as etapas do desenvolvimento do projeto, incluindo pesquisa teórica, observação prática, análise dos dados e criação do material educativo.

### Folder

Apresenta a proposta de criação de um folder educativo para auxiliar na conscientização dos alunos.

### Galeria

Reúne imagens e ilustrações relacionadas aos elementos de acessibilidade analisados.

### Referências

Lista as principais normas e materiais utilizados como base técnica para o projeto.
